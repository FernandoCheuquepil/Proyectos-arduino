# Proyectos Arduino

Colección de proyectos y ejemplos para Arduino en español.

## Proyectos incluidos

### 1. Blink LED
Proyecto básico que hace parpadear un LED. Ideal para comenzar con Arduino.
- **Dificultad:** Principiante
- **Hardware:** Arduino Uno, LED (opcional)

### 2. Sensor de Temperatura
Lee la temperatura usando un sensor TMP36 y muestra los valores en el Monitor Serial.
- **Dificultad:** Principiante
- **Hardware:** Arduino Uno, Sensor TMP36

## Estructura de los proyectos

Cada proyecto tiene su propia carpeta con:
- Archivo `.ino` (sketch de Arduino)
- `README.md` con instrucciones específicas del proyecto

## Cómo usar

1. Clona este repositorio
2. Abre el archivo `.ino` del proyecto que quieras en el Arduino IDE
3. Sigue las instrucciones en el README.md de cada proyecto
4. Sube el sketch a tu Arduino

## Requisitos

- [Arduino IDE](https://www.arduino.cc/en/software) (versión 1.8 o superior)
- Placa Arduino (recomendado: Arduino Uno)
- Componentes específicos de cada proyecto
